# v1.7 手机直屏早晨布局与镜子镜头 · 结果

只改了 `原型/v1.7/index.html`，并重打了 `原型/v1.7/index.packed.html`。没有改 v1.6 或更早的版本，也没动玩法数值、音乐和美术。标题仍是「戏城 v1.7」。没有 commit，也没有 push。

## 根因（对照玩家原图）

| 玩家原图的问题 | 实际原因 |
|---|---|
| 镜子只露出右边一角 | 早晨用的是全桌视角 `VIEWS.table`。直屏时 `focus()` 把镜头拉远 1.72 倍，但直屏的水平视角只有约 21°，看得到的宽度大约是 x∈[-1.15, 1.15]，而镜子在 x=1.32，所以被挤出了画面。另外妆匣在 x=-1.32，也一样出画，这点 brief 里没提到。 |
| 桌子被挤扁，桌子和「出门」之间一大块空白 | 镜头按整个窗口的中心构图，但上面约 280px 被顶栏占掉，下面被字幕和手牌占掉，所以桌子挤在上半部，前景的空桌面落在字幕上方。 |
| 顶栏过高 | 窄屏时木牌是三行竖排（约 94px），水牌有三行名次加考核（约 93px），再加乐和规矩两个按钮，第一行就有 129px；再加上折下来的妆匣标题和情报，共两行。 |
| 熄／痕和图鉴压在场景中间 | 手机上 `renderLeft()` 会把左栏放在顶栏底下（brief 猜的 `top:158px` 其实已被 JS 覆盖）。左栏位置本身没错，只是顶栏太高，把它推到了 y≈243，正好在 3D 主体上，而且镜头完全没有避开它。 |

## 改了什么

### CSS（`</style>` 前新增一段，只在直屏手机 `@media (max-width: 760px) and (orientation: portrait)` 生效）
- 木牌改成横排单行：第 N 天、起手圆章、卖座。
- 水牌缩成小签：不再列三行名次，只留「水牌 第 N / 6」、差距和考核（考核可以折成两行，「别垫底」不会被截掉）。小签和乐、规矩排在同一行。
- 妆匣标题、情报的字级和内距缩小，今晚和明晚两条情报能排在同一行。
- 字幕的内距和字级稍微缩小。
- 360px 左右时，木牌上省掉「起手」两字，只留圆章。
- 结果：在 390×844 上，顶栏加家和图鉴那一条，底部从 y≈280 降到 y≈150。

### 镜头（`focus()` 一带）
- 新增 `portraitPhone()`，判断条件是 `innerWidth ≤ 760` 且高大于宽。
- 新增 `VIEWS.tableP = { pos: [0.46, 2.7, 4.2], look: [0.74, 1.0, -0.5] }`。只有「早晨 + 直屏手机」才会改用它，桌面、横屏和其他时段仍然用原来的 `table`。镜头往右移，对准她和镜子之间：阿檀在左，镜子在右，两个都完整入镜，镜子里的脸看得清楚。妆匣（左侧木匣）在这个角度出画，但早上的妆匣本来就是底下那排手牌。
- 新增 `camBand()`：在直屏手机上量出顶栏和左栏的底部，以及字幕（或事件卡、按钮、手牌）的顶部，用 `camera.setViewOffset()` 把投影中心平移到这一带的正中间。它只平移，不缩放，所以所有时段在直屏上都会对着真正看得见的那一块。宽屏和横屏会清掉这个偏移，行为和原来一样。
- 字幕变高或变矮时，偏移量在 `loop()` 里慢慢跟过去，不会跳动；换时段、resize 时直接到位；开了「减少动态」时也直接到位。
- resize 或旋转屏幕时会用上一个镜头重新 `focus()`。原来转成直屏后要等下一次换镜头才会套用新的距离系数。
- `refresh()` 末尾会调用 `camBand()`，HUD 高度一变就更新。

### 布局逻辑（`fitSpread()`）
- 直屏早上后台（第 3 天起）摊开的卡组，原来从 `mid.top` 开始，盖住了熄／痕和图鉴。现在把家和图鉴那一条也算进顶栏，卡组从它底下开始。宽屏的计算没有动。

## 期望效果逐条

1. 镜子里的自己：直屏早晨镜子完整入镜，脸清楚（见 01、04）。✅
2. 镜头对准可见带：投影中心平移到顶栏和字幕之间，桌子、她和镜子都没有被 HUD 切掉。✅
3. 顶栏收紧：在 390×844 上，从约 280px 降到约 150px（包括家和图鉴那一条）。✅
4. 图鉴不再压到灯和熄／痕：它们本来就在同一行没有重叠。现在这一条紧贴在顶栏底下，镜头也会避开它；后台摊开的卡组不会再盖住它。✅
5. 「出门」和对白上移：字幕和按钮的位置由手牌决定，没有搬动。原来的空白是镜头按整个窗口构图、前景只拍到空桌面造成的。现在 3D 内容填满了这一带，字幕上方紧接着桌面、蜡烛和金钱。在 390×844 这种很高的屏幕上，镜子下沿到字幕之间仍有大约 50px 的桌面，因为窄屏装不下更大的画面；在微信高度（390×680）下几乎没有空白。基本达成。
6. 手牌：位置和大小没变，仍然可以点、可以看说明，没有被字幕或按钮挡住。✅
