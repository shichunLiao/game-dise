# 《底色·戏城》美术规划

> 目标：把 v0.8 原型从「程序画的低模」升级成作品集级的唯美画面。
> 分工：**插画师（你）手绘**有情绪、有角色身份的部分；**Codex（gpt-6.1sol）生图**量大、可变体、偏材质与装饰的部分。给 Codex 的逐项需求见同目录的 `codex_生图需求.md`。

## 一、风格方向

### 1. 从三张参考图里取什么

| 参考 | 取 | 不取 |
|---|---|---|
| 图一（柳下孤舟、双鹤） | 大面积留白的宣纸底；水墨晕染的树石；白描细线勾人物衣纹；**只用朱红点题**（唇、腰带、日、鹤顶）；纯黑剪影与倒影 | 具体构图、人物造型 |
| 图二（红幕后台四格） | 红幕把画面框成「戏台」；后台墙上一排脸谱、戏服；暖纸色水彩；幕后偷看的小孩，是「台上 / 台下」的视角 | 写实的现代场景 |
| 图三（红黑扑克） | 卡面：朱红底、细密对称的纹样、墨黑与青灰点缀、四角做旧的边框 | 西洋花色与 JOKER 字样 |

三张图都是别人的作品，只当情绪参考：不临摹、不图生图、不在生图提示里写作者名。

### 2. 一句话风格

**宣纸上的水墨与白描，朱红只用在要紧处；台下是黑色剪纸，台上是红幕与脸谱。**

### 3. 色板

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 宣纸白 | `#ECE3D4`、亮部 `#F4EFE6` | 底、家里面的牌、面板 |
| 墨黑 | `#120E11`、`#1C1719` | 线、剪影、夜 |
| 灰墨 | `#8D8487` | 晕染、远景 |
| 朱红 | `#A8202B`、亮 `#C8283A` | 幕、印章、要紧的字、唱族 |
| 赭金 | `#B8913F`、亮 `#F2D48A` | 金箔、情报、打族、边框 |
| 青灰 | `#4F6B66`、深 `#2E4441` | 卡面纹样点缀、夜色里的冷调 |
| 土褐 | `#8F6338` | 做族、木器 |

四族颜色不变：唱＝朱红、念＝墨黑、做＝土褐、打＝赭金。

### 4. 笔触与质感规矩

- 底：带纤维的宣纸纹理，不要纯色平涂。
- 线：白描细线勾轮廓，粗细有变化；不用数码硬描边。
- 面：水墨晕染、半干笔的飞白；局部薄水彩。
- 红：一张图里朱红面积不超过三成（红幕场景除外）。
- 剪纸：纯黑剪影，外缘一圈细朱红纸边，带一两处镂空窗花（原型里已经是这个做法）。
- 不要：赛博、写实摄影感、塑料高光、3D 渲染感、日系赛璐璐上色、西式哥特花纹。

## 二、3D 换成什么：建议「2.5D 纸偶戏台」

现在的画面是 Three.js 低模（卡通着色的方块、程序画的人物）。三个选择：

| 方案 | 做法 | 好处 | 代价 |
|---|---|---|---|
| A 保留 3D，只换贴图 | 模型不动，把木纹、幕布、灯笼换成手绘贴图 | 改动最小 | 人物还是低模，「不精细」的问题解决不了 |
| **B 2.5D 纸偶戏台（建议）** | 保留 3D 的镜头、桌面布局和推拉，但**所有角色和道具都换成手绘的平面立牌**（像纸扎、皮影），分层摆在 3D 空间里 | 画面就是你的插画；镜头推拉、视差、光影还在；和剪纸观众、卡牌风格统一；人物用分件立牌做皮影式小动作 | 人物要拆成几块画（头、身、袖、手）；需要我改代码 |
| C 纯 2D 分层场景 | 不用 3D，每个时段一张分层插画，CSS 视差 | 最好画、最好控 | 失去镜头在桌上移动的感觉 |

**选 B 的理由**：这个游戏的核心画面就是「一张桌子、一个小戏台、对面坐着她」，镜头推拉本身就是叙事（推近戏台、拉到门口、看向镜子）。B 保住了这件事，同时让每一个可见的东西都是手绘的。皮影和纸扎本来就是戏曲周边的民间形式，和「面具、台上台下」的主题也合。

### B 方案怎么拆

| 现在（代码里） | 换成 |
|---|---|
| `makeFigure` 程序人物（阿檀、台上的你） | 分件立牌：头、身、左右袖、手各一张透明 PNG，代码里像皮影一样转动关节 |
| 桌面、墙、地板的程序纹理 | 手绘贴图（木纹、窗格墙、地面） |
| 小戏台的幕、竿、灯笼 | 幕布贴图 + 灯笼立牌（亮 / 暗两张） |
| 灯坊的灯（12 片红纸、痕） | 一张灯笼底图 + 12 片纸的分层 + 3 种划痕贴图 |
| 木匣、妆匣、镜框、毛巾、金箔、蜡烛、布 | 每样一张立牌或贴图 |
| 镜子里的脸（`drawPortrait`） | 一张素脸 + 四族油彩各一层 + 底色一层，代码按层叠 |
| 剪纸观众 | 直接换成生图的剪纸剪影（现在就是平面，最容易换） |
| 卡面（`cardArt`） | 卡框 + 中间插图换成图片；**牌名、金、接、背面这些字继续由代码写**，数字改了不用重画 |
| 特效（纸屑、金箔、彩绸、墨点） | 换成小图精灵，代码照旧撒 |

## 四、做的顺序

1. **风格样张（先做，定方向）**：三张定调图，不进游戏，只用来确认方向。
   - 样张一：白天戏台，俯看，红幕、台板、两张打出去的牌、前排剪纸观众。
   - 样张二：傍晚灯坊，对面的阿檀（等），桌上的灯笼和碗筷。
   - 样张三：卡牌一套（一张台上面、一张家里面、牌背）。
   建议样张二由你画，样张一、三由 Codex 出几版、你挑一版修。
2. **P0**：H1–H4、H8 与 C1–C5。做完这一批，画面主体就换掉了。
3. **P1**：H5–H7 与 C6–C8。
4. **P2**：H9、H10 与 C9、C10。

## 五、交图规格（两边都按这个交）

- 格式：PNG；需要透明的一律带透明通道，边缘不留白边、不留灰边。
- 尺寸：贴图用 2 的次方（1024、2048）；立牌按上面表格。
- 命名：小写拼音加下划线，例如 `atan_wait_head.png`、`card_frame_sing.png`；放进 `原型/assets/` 下对应的子目录：`chars/`、`scene/`、`props/`、`cards/`、`ui/`、`fx/`、`endings/`。
- 分件立牌：同一个姿态的各块**在同一张画布上对齐**导出（画布一样大、位置不动），我在代码里按画布坐标拼回去；另附一张合起来的预览图。
- 卡面插图**不放任何文字**：牌名、金、接、背面都由代码写上去，数字以后改了不用重画。
- 每张图附一行说明：编号、文件名、哪一面、有没有透明。

## 六、接进游戏要注意的一件事

现在原型是一个 HTML 文件，双击就能玩。换成图片以后，浏览器不让 3D 从本地文件读取图片（`file://` 下 WebGL 贴图会报安全错误），所以两条路：

1. 用一个本地小服务器打开（`python3 -m http.server`），或者放到 GitHub Pages 上，网址打开就能玩；
2. 或者我写一个打包脚本，把所有图片转成内嵌数据，仍然导出成一个 HTML 文件（文件会变大，几十 MB）。

作品集展示建议用 GitHub Pages；平时自己试玩可以用打包后的单文件。图交过来以后，接线由我来做。
