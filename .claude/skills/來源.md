# 專案 skill 來源

這個目錄的 10 個 skill 取自 [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)（Apache-2.0，授權原文見 `LICENSE-awesome-gamedev-agent-skills`），固定在原 repo commit `19d93f97c9c1ea0f8b306e77aa81e0d3e352d3e9`。收錄副本在 `shichunLiao/agent-skills` 的 `game-dev/awesome-gamedev-agent-skills/`。

| skill | 在《底色》裡用來做什麼 |
|---|---|
| threejs-scene-setup | 原型/v0.4 的場景、相機與渲染迴圈 |
| threejs-materials-lighting | 水墨風的材質與打光 |
| threejs-gltf-loading | 之後把程序化人偶換成 glTF 模型與動畫 |
| card-game | 卡組、妝匣、手牌與出牌結算 |
| visual-novel | 劇情演出、字幕與選項 |
| dialogue-systems | 阿檀與更夫的分支對話、需求線索 |
| game-ui-ux | 手牌、浮層選項、手機與桌面的版面 |
| audio-design | 鑼鼓、雨聲、梆子等音效與配樂 |
| shader-programming | 水墨描邊、紙紋、墨染轉場 |
| create-game-assets | 美術方向與卡面、人物素材的生產流程 |

`create-game-assets/scripts/` 的兩支 Python 腳本只用 Pillow 處理本地圖片，收錄時沒有執行。
