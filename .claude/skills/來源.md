# 專案 skill 來源

這個目錄有 25 個 skill，來自四個上游，收錄副本都在 `shichunLiao/agent-skills`。腳本收錄時都沒有執行。

## awesome-gamedev-agent-skills（10 個）

來源 [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)，Apache-2.0（授權原文見 `LICENSE-awesome-gamedev-agent-skills`），固定在 commit `19d93f97c9c1ea0f8b306e77aa81e0d3e352d3e9`。

| skill | 在《底色》裡用來做什麼 |
|---|---|
| threejs-scene-setup | 原型/v0.4 的場景、相機與渲染迴圈 |
| threejs-materials-lighting | 水墨風的材質與打光 |
| threejs-gltf-loading | 之後把程序化人偶換成 glTF 模型與動畫 |
| card-game | 卡組、妝匣、手牌與出牌結算 |
| visual-novel | 劇情演出、字幕與選項 |
| dialogue-systems | 阿檀與更夫的分支對話、需求線索 |
| game-ui-ux | 手牌、浮層選項、手機與桌面的版面 |
| audio-design | 鑼鼓、雨聲、梆子等音效與配樂 |
| shader-programming | 水墨描邊、紙紋、墨染轉場 |
| create-game-assets | 美術方向與卡面、人物素材的生產流程 |

`create-game-assets/scripts/` 的兩支 Python 腳本只用 Pillow 處理本地圖片。

## threejs-game-skills（9 個）

來源 [majidmanzarpour/threejs-game-skills](https://github.com/majidmanzarpour/threejs-game-skills)，MIT（授權原文見 `LICENSE-threejs-game-skills`），固定在 commit `8286774b22a2566bf894dbc825825c16921866af`。

| skill | 在《底色》裡用來做什麼 |
|---|---|
| threejs-game-director | 入口：要做整體升級或收尾時，由它分派給下面幾個 |
| threejs-gameplay-systems | 玩法系統；附 Vite＋TypeScript 範本與自動試玩測試範本 |
| threejs-aaa-graphics-builder | 把程序化人偶與場景往上提升，附 10 項視覺評分表 |
| threejs-game-ui-designer | 手牌、浮層選項、觸控與安全區 |
| threejs-qa-release | 自動試玩、手機檢查、截圖比對、畫布像素檢查、上線 |
| threejs-debug-profiler | 除錯與效能分析 |
| threejs-image-generator | 用 Gemini 生成卡面、背景等 2D 素材（需要 `GEMINI_API_KEY`） |
| threejs-3d-generator | 用 Tripo 生成並綁骨阿檀等 3D 角色（需要 `TRIPO_API_KEY`） |
| threejs-audio-generator | 用 ElevenLabs 生成音效與配樂（需要 `ELEVENLABS_API_KEY`） |

三個生成類 skill 要自備 API 金鑰，使用時可能產生費用；腳本只連線到本機與這些服務的官方 API。
