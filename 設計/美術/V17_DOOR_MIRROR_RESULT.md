# v1.7 手机直屏「门口卸妆」镜子被挡 · 结果

只改了 `原型/v1.7/index.html`，并重打了 `原型/v1.7/index.packed.html`。没有改玩法、音乐、音效、美术，也没动 `lastwipe`（`#wipe`）。标题仍是「戏城 v1.7」。没有 commit，也没有 push。

## 根因（已验证，与 brief 一致）
门口走 `focus('door')`，用的是 `VIEWS.door`。直屏时 `fit = 1.72` 把镜头拉远，但直屏手机的水平视角只有约 21°，镜子（x=1.32）被挤出右边，只剩一圈金框。`camBand()` 只做垂直平移，帮不上忙。夜里 `VIEWS.night` 略微偏右，所以镜子露出一半。

## 改了什么（都在 `focus()` 一带）
1. **`VIEWS.doorP = { pos: [0.39, 1.94, 5.9], look: [0.66, 1.1, -0.5] }`**：只在门口 + 直屏手机（`portraitPhone()`）时启用。
   - 镜头比早晨的 `tableP`（高 2.7）低、更平，像刚进门站着看桌子，不是早晨那种偏高的俯视。灯光仍是 `MOODS.door`。
   - 构图：阿檀在左，起身伸手（`pose('reach')`）时手臂也完整入镜；镜子在右，整面入镜，油彩看得清楚。
2. **`VIEWS.nightP = { pos: [0.5, 1.75, 5.5], look: [0.7, 1.0, -0.4] }`**：夜里（`night` 和 `watch`）直屏也改用这个视角，镜子完整。
3. `focus()` 改成通用规则：直屏手机时，`PORTRAIT_VIEWS = ['door', 'night']` 里的视角会改用对应的 `…P` 版本；早晨 `table` 改用 `tableP` 的规则不变。
4. 所有 `…P` 视角的距离系数从固定的 1 改成 `max(1, 0.462 / aspect)`。这些视角是按 390×844 调的，更窄的手机（如 360×800）会按比例略拉远，镜子不会贴边。390×844 和 375×812 不受影响（系数等于 1）。
5. **毛巾 `towelSwipe()`**：毛巾挂在镜头上，直屏视野窄，原本的大小会盖满整个画面，只闪一下。改前就是这样，不是这次造成的，但新镜头下更明显。现在只在直屏手机上，按画面宽度缩窄毛巾和它的移动路径（`sx = max(0.3, aspect / 1.6)`），看起来是一条毛巾从左擦到右。桌面和横屏 `sx = 1`，和原来一样。

桌面、横屏仍走原来的 `VIEWS.door` 和 `VIEWS.night`，没有变化。早晨的 `tableP`、顶栏 CSS、`camBand()` 也都没改。

## 取舍
- 要让阿檀（含伸出的手臂）和整面镜子同时进窄画面，镜头只能拉远。镜子在 390 宽下约 120px，和早晨 `tableP` 差不多。脸和油彩层数看得清，但不是特写。如果要更大，就得切掉阿檀，这与 brief 第 2 条冲突，所以没这样做。
- 门口直屏画面里，镜子底座到字幕之间还有一段暗色桌面。门口有两个选项按钮，可见带比早晨矮，现在内容已在这一带里居中。
