# 戏城 v1.7：修手机直屏早晨布局与镜子镜头

请先读完本说明再动手。这是对现有 v1.7 的局部修正，不是重做一版。

## 任务

玩家用手机竖屏试玩时，早晨「妆匣装好了」这一幕布局不合理，而且从这个角度看根本看不到镜子里的自己。请修好手机直屏（尤其是早晨）的镜头与 HUD 布局，让镜子里的脸清楚可见，界面不再把 3D 画面挤扁或互相重叠。

改完后请自检、截图对照，再打包 `index.packed.html`，并写结果文档。不要提交、不要推送、不要改其他版本。

玩家截图（请先打开看）：

`/Users/tsun/Projects/game-xicheng/設計/美術/feedback_v17/phone_morning_day2.jpg`

这是手机直屏、第 2 天早晨、妆匣已装好、准备出门的画面（可能在微信或系统浏览器打开 https://shichunliao.github.io/game-xicheng/）。能看到的问题：

- 镜子只剩画面右侧一小角，里面的脸几乎看不清。玩家原话：「在这个角度看根本看不到镜子里的自己」。

- 3D 可见区域被挤得很扁。

请以这张图为准，自己再在手机尺寸下复现并修。不要只听下面的猜测。

## 假设（请自行验证，可推翻）

主文件是单文件游戏 `/Users/tsun/Projects/game-xicheng/原型/v1.7/index.html`。

镜头相关（约 2387–2410、4009–4014 行）：

- 早晨 `placeScene()` 用的是全桌俯视 `focus('table', 'day')`。
- `VIEWS.table = { pos: [0, 2.2, 2.72], look: [0, 0.62, -0.42] }`，镜子在桌子右侧。
- `focus()` 在 `camera.aspect < 0.8`（直屏）时把镜头再拉远 `fit = 1.72`。宽屏上右边的镜子还看得到；直屏拉远后，桌子被挤成中间一条，镜子几乎出画。
- 已经有对着镜子的近景 `VIEWS.mirror = { pos: [1.02, 1.26, 1.06], look: [1.3, 1.14, -0.02] }`，目前用于季末卸妆 `lastwipe`，早晨没用。镜子画布由 `updateMirror()` 画玩家肖像。
- 直屏早晨也许需要一个略靠右、较近的角度（不必照搬卸妆近景，也不一定要新建独立 view），并让 3D 内容落在顶栏和手牌之间那块真正看得见的区域，而不是按整个窗口中心构图。

布局相关（约 67 行 `.leftcol`，以及 `@media (max-width: 760px)` 约 474–549 行）：

- 桌面 `.leftcol` 是 `top: 158px`。手机媒体查询改了 left／flex／宽，但似乎没改 `top`，顶栏折成两行之后，「熄／痕」和「图鉴」可能就压在场景中段。
- 顶栏偏高；「出门」和对白离桌子太远，中间空白过大。

这些都只是假设。请自己读代码、在目标尺寸下截图验证，再决定怎么改。若根因不同，按你的判断修，并在结果里写清楚。

## 期望效果

手机直屏早晨（以玩家这张「第 2 天、妆匣装好了」为准）：

1. 镜子里的自己清楚可见，不能只剩边角或看不清脸。
2. 镜头对准顶栏和手牌之间的可见带，不要被 HUD 切掉桌子或镜子的关键部分。
3. 顶栏收紧，少占垂直空间。
4. 「图鉴」不要压到灯和「熄／痕」；左侧状态与图鉴不要叠在场景主体上。
5. 「出门」和对白上移，靠近桌子，去掉那一大块空白。
6. 手牌仍可点、可看说明，不被对白或按钮挡住。

同时请兼顾：

- 桌面宽屏、手机横屏不要明显回退。早晨在电脑上仍应能看见桌子全貌和镜子，不需要改成手机那种近景。
- 其他时段（台上、门口、傍晚、夜里、商店、规矩、结局等）在手机直屏上也要检查一遍，有明显重叠或大块浪费再顺手修；没有就不要大改。
- 已知、本轮不要做的问题：五样新货（班鼓、香粉、手抄折子、耍牙、甩发）仍无图；手机横屏「满堂红」大字可能短暂压在牌与收场钮上；手机直屏事件卡会盖住早晨卡组上半。不要顺手改音乐（玩家明确说这轮不要动音乐）。
