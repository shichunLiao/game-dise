# 底色

> 最上面的面具決定你得到什麼，最底下的面具決定你傷害誰。

單人策略卡牌遊戲。你在工作、家人、伴侶之間疊戴面具，搶時間衝績效。績效是公開的，關係是隱藏的，要等你贏了才翻開。

## 目錄

| 位置 | 內容 |
|---|---|
| `設計/v0.1_疊面具x雙賬本.md` | 最小規則集與數值自檢 |
| `設計/v0.2_遊戲概念草稿.md` | 擴充設計：支柱、三個世界觀、章節、事件、結局 |
| `設計/模擬/` | `sim.py` 窮舉驗證數值，`story.py` 重現範例一局 |
| `設計/說明PDF/` | 產生 `設計/底色_遊戲概念說明.pdf` 的腳本 |
| `原型/index.html` | 網頁原型（B《底色》世界觀，v0.1 規則五天加揭曉） |
| `原型/check_engine.js` | 核對原型規則引擎和 `sim.py` 是否一致 |

## 執行

```bash
python3 設計/模擬/sim.py      # 加 -v 看每一步最優走法
node 原型/check_engine.js
python3 設計/說明PDF/build.py  # 需要 Google Chrome
```

原型直接用瀏覽器打開 `原型/index.html`。
