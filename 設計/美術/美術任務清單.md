# 《底色·戏城》美术任务清单 v2（纸片进戏台）

> 方向：**画在纸上的牌和纸片，摆在原型的 3D 桌面上**（像《邪恶冥刻》）。3D 场景基本不动，你能看清楚的东西换成画的。
> 分三栏：**你画**、**Codex 画**、**我接线**。做完一项就把 `[ ]` 改成 `[x]`。
> 每项的规格写在：你的 → `插畫師繪製要求.md`；Codex 的 → `codex_生圖需求.md`；方向与理由 → `美術規劃.md`；原型现在的样子 → `原型截圖/`。

## 先后

| 阶段 | 做什么 | 过关的样子 |
|---|---|---|
| 第 0 步 风格锁定 | 你画一张阿檀纸片试样；Codex 出 5 项小样；我把它们放进游戏和截图里 | 你看着说「就是这个味道」。**不过关，后面不开工** |
| P0 | 卡面、卡纸、观众；阿檀、台上的你、镜中的脸、纹章 | 打开游戏，主要画面都是画的了 |
| P1 | 装饰纸片、物件、界面、特效；结局牌、标题、木匣、她走了 | 作品集能截的画面齐了 |
| P2 | 夜景、同门、更夫、卸妆底图 | 全部换完 |

**卡住别人的，最先做**：第 0 步（卡住全部）、H8 八枚纹章（卡住 Codex 的卡面插图）、C10 同门草稿（卡住你的 H10）。

**不做了**（上一版有，这一版删掉）：桌面、墙、地板、台板、幕布的写实贴图；灯、木匣、镜框、毛巾、蜡烛等道具的写实立牌。原型的 3D 场景保留。
