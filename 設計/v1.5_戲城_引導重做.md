# v1.5 戲城 · 引導重做

規則、數值與 v1.3 完全相同（`原型/v1.5/check_engine.js` 照跑 v1.3 的核對）。只改界面和引導。v1.4 中刪版未採用。

原型：`原型/v1.5/index.html`

## 一、「她今晚要」的牌不再變形

v1.3 的問題：牌上加了 `need` 這個 class，和頂上「她的需要」框的 `.need` 樣式撞了名，手牌被套上 flex 和內距，畫面被擠窄；底下那條金框也對不齊牌上的「背 X」。

現在：
- class 改名 `want`，不再撞名。牌的形狀、大小、角度和其他牌完全一樣。
- 拿掉了對不齊的內框。

兩種提示，樣子分開：

| | 樣子 | 什麼時候 |
|---|---|---|
| 能打／該推 | 一圈金框、金光 | 台上：接得上的牌；傍晚：她要的、推了不會被染的牌 |
| 她今晚要的牌 | 牌本身不變（不壓暗、不加框），頂上蓋一枚小朱印「家」 | 早上、台上、門口都一樣：帶上它，留著回家 |

台上印著「家」的牌即使接得上，也不給金框（它不是建議打的牌），但照樣能打。手牌底下一行寫著「金框的能打 · 印着「家」的留着回家」。

## 二、教學：從「讀了按知道了」改成「照著做」

| | v1.3 | v1.5 |
|---|---|---|
| 第 1 天要按「知道了」 | 約 10 次 | 3 次（你的臉、一張牌兩面、她的燈） |
| 開場的抽象介紹（「戲城」） | 有 | 拿掉，直接教第一步 |
| 做的步驟 | 也有大框、標題、說明 | 只一句話，貼在要點的東西旁邊，畫面只輕微壓暗；做對了自動往下 |
| 看的步驟 | 標題＋說明＋「記住」 | 同樣三行，但全程只剩四處：第 1 天門口、第 1 天夜、第 2 天早上、第 3 天早上 |
| 其餘提醒（水牌、圖鑑、台下情報、讓她擦、她會走、後台、百搭、怨氣、家常牌） | 擋畫面的教學框 | 不擋畫面的小提示：貼在新出現的東西旁邊，9 秒自己收，點一下也收；一次只有一條，每條只出一次 |

第 1 天的流程（每步做對了就往下）：

1. 點「長腔」——第一張打木牌上的起手。
2. 點「白」——長腔寫著接念，打念就接上了。
3. 再接兩張——浮起來的都接得上。
4. 點收場——四張了，見好就收。
5. 門口：看一眼鏡子（你的臉，一次「好」）→ 點牌卸妝直到卸乾淨。
6. 夜裡：**一張牌，兩面**——今天打的第一張牌在框裡翻面（台上面 長腔 ↔ 家裡面 傾聽）：「台上打掉、卸妝棄掉的，今晚就沒了；留在手裡的，回家翻過來推給她。」→ 她的燈。

其他規矩：
- 教學換了場景（比如從傍晚到夜裡）就算教完，不會跟著帶過去。
- 第 2 天傍晚「推給她」那一步，手上只剩被染的牌時改說「推了，燈上留一道痕；下回卸乾淨再進門」，不再叫你「先推一張不要緊的」。
- 做的步驟的說明框放在手牌左邊，不蓋住朱紅主按鈕；窄螢幕放上面。

## 三、一個時刻只說一件事

- 教學框或小提示在畫面上時，台下觀眾不插閒話（情報、同門的事照說）。
- 台下說了她今晚要什麼，只出一個金框氣泡；不再同時在字幕重複一遍。
- 彩帶、煙火、花瓣只在戲台上放；一離開戲台就收掉，不再飄進卸妝那一步。

## 四、裝妝匣

- 攤開的那一格標上「卡組 · 點一張放進妝匣」。
- 底下那排標上「妝匣裡的 · 點一張拿回去」。
- 頂上的「裝妝匣 n/10」不變（一級焦點）。

## 五、主次（沿用 v1.2 的三級）

- 一級：頂上金字焦點句、朱紅主按鈕。教學不搶這兩樣：做的步驟的說明框讓開主按鈕。
- 二級：字幕（故事）。教學在時字幕照常，但台下閒話停。
- 三級：小提示、小籤、詞條虛線。小提示一次一條，自己會收。

## 六、待試玩確認

1. 第 1 天照著做完以後，玩家能不能自己說出「接口」「卸妝」「一張牌兩面」。
2. 小提示 9 秒自己收，會不會太快、沒讀完。
3. 「今晚要」小籤在手牌很多張時會不會擠。
