# 《底色·戏城》美术规划（v2：纸片进戏台）

> 对照原型 v1.0。打勾用的清单见 `美術任務清單.md`；给 Codex 的逐项要求见 `codex_生圖需求.md`；给插画师（你）的绘制要求见 `插畫師繪製要求.md`。
> 原型现在的样子见 `原型截圖/` 里的截图和卡面一览：**新画的东西要放进这个画面里不违和**。

## 一、这一版为什么重写

上一版把「换成手绘」理解成了「把场景画得更真」，Codex 照着出的图太写实：木纹、幕布、道具都像照片，放进原型就跳出来了。

这一版换个方向：

> **画在纸上的牌和纸片，摆在一张真实的桌子上。**

像《邪恶冥刻》那样：桌子、灯、烛光、镜头推拉是 3D 的，**你能看清楚、拿在手里的东西都是平面的、画出来的**——卡牌、观众、角色、贴在墙上的剪纸。3D 负责空间和光，2D 负责内容和情绪。

## 二、保留什么、换什么

| | 保留原型（基本不动） | 换成画的 |
|---|---|---|
| 场景 | 桌子、房间、小戏台的结构、幕、竿、蜡烛、镜框、灯坊的灯、木匣、妆匣、晾绳 | 墙上加窗花和剪纸、戏台后加一幅「守旧」背幕图案、台上铺一块纹样台毯、灯纸印上纹样 |
| 卡牌 | 版式不动：族徽、牌名、金、关键词、「接 →」、背面横条都还是代码写字 | 中间加一幅插图（木刻／剪纸／白描的平面图形）；卡纸加纸纹、磨边、印刷感 |
| 观众 | 剪纸做法不动：纯黑剪影、朱红纸边、立在台前、一起起伏 | 形状丰富：从现在 5 种头型变成 40 个不同的人，有动作、有道具、有前后排 |
| 阿檀 | 位置、镜头、反应的时机不动 | 程序做的白色低模人 → **你画的纸片**，立在桌对面 |
| 台上的你 | 同上 | 程序人 → 你画的纸片，四族身段换着立 |
| 镜中的脸 | 镜框不动 | 程序画的脸 → 你画的分层脸 |
| 界面 | 布局、字不动 | 底纸、印章、小图标换成同一种纸感 |

**一条底线**：新图放进原型截图里比一比，色调、明暗、笔触要和周围一致。比不过去的，不收。

## 三、风格

### 1. 三张参考取什么（只取方法，不临摹）

| 参考 | 取 |
|---|---|
| 红底白衣的戏曲人物 | 人物是「纸」：白色宣纸剪出的人形，墨线白描，飞白；人在大面积纯色里；一道浓黑的投影把人钉在地上 |
| 红黑灰的塔罗牌 | 平面构成：俯视、对称、几何（扇形、圆环）；三四个颜色就够；图形感强，像海报 |
| 黑底白线的卡牌 | 木刻／版画：黑底上刻出白线，线粗、块面分明；卡面信息分区清楚 |

这三张都是别人的作品，只当方向参考：**不放进仓库、不图生图、不在提示词里写作者或作品名**。

### 2. 一句话

**平面、图形、有设计感：墨线白描或木刻线，三四个颜色，纸的质感；光影交给 3D，画里不画光。**

### 3. 色板（不变）

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 宣纸白 | `#ECE3D4`、亮部 `#F4EFE6` | 纸片底、家里面的牌 |
| 墨黑 | `#120E11`、`#1C1719` | 线、剪影 |
| 灰墨 | `#8D8487` | 次要块面 |
| 朱红 | `#A8202B`、亮 `#C8283A` | 唱族、点题、纸边 |
| 赭金 | `#B8913F`、亮 `#F2D48A` | 打族、金箔、细边 |
| 土褐 | `#8F6338` | 做族 |
| 青灰 | `#4F6B66` | 少量冷色点缀 |

四族颜色不变：唱＝朱红、念＝墨黑、做＝土褐、打＝赭金。

### 4. 一票否决（出现就不收）

- 照片感、写实材质（真木纹、丝绒反光、金属高光）、景深虚化、体积光。
- 画里自带的强烈明暗、投影、环境光（光由 3D 加）。
- 3D 渲染感、塑料感、赛博、日系赛璐璐、西式哥特花纹。
- 画面里有字（汉字、字母、数字、签名、水印）。
- 颜色超出色板太多、一张图超过五个颜色。

## 四、纸片怎么进 3D（你和我都要知道）

1. **纸片就是一张带透明的图**，贴在 3D 空间里一块薄板上，立在桌上或台上。
2. **画不被光吃掉**：纸片上的图按原色显示（亮度只在 85%–100% 之间随场景微调），不会被灯照得发黄发黑、看不清。
3. **光影加在纸片外面**：
   - 纸片投在桌上、墙上的影子（像参考一里那道黑影）；
   - 纸边的一圈暖色轮廓光（蜡烛那一侧更亮）；
   - 纸片稍微有厚度、边缘一圈纸色，转动时看得出是一张纸；
   - 夜里、她难过时，整体最多压暗 15%，加一层很淡的冷色。
4. **动起来像纸偶**：换姿态＝换一张纸（翻过去再翻回来，或啪地换掉）；小动作是整张纸轻轻晃、头那一块单独点一下。不做骨骼动画。

这些是我在代码里做的；你画的时候**不要画环境光和投影**，只画人和纸边。

## 五、做的顺序

1. **风格锁定**：Codex 出 5 张小样（两张卡面插图、一组观众剪影、一张装饰纸片、牌背），我把它们放进原型截图里，你挑定。同时你画阿檀「等」的一张纸片，我先接进游戏看效果。**这一步不过，后面不开工。**
2. **P0**：卡面插图、卡纸质感、观众剪影；阿檀全部姿态、台上的你、镜中的脸、八枚纹章。做完这批，画面主体就是新的了。
3. **P1**：装饰纸片、物件图标、界面、特效；结局牌、标题、她走了、木匣。
4. **P2**：夜景、同门木刻像、更夫、卸妆底图。

## 六、交图规格（两边都按这个交）

- 格式：PNG，需要透明的带透明通道，边缘干净，不留白边、灰边、阴影底。
- 命名：小写拼音加下划线，例如 `atan_wait.png`、`art_changqiang_line.png`；放进 `原型/assets/` 下的子目录：`chars/`、`face/`、`cards/`、`crowd/`、`deco/`、`relics/`、`ui/`、`fx/`、`night/`、`endings/`、`draft/`。
- 卡面插图、纸片**都不放任何文字**：牌名、数字由代码写。
- 每个子目录附一个 `README.md`：一行一张，编号、文件名、尺寸、透明与否、一句说明。

## 七、接进游戏要注意的一件事

现在原型是一个 HTML 文件，双击就能玩。换成图片以后，浏览器不让 3D 从本地文件读图（`file://` 下 WebGL 贴图会报安全错误），所以两条路：

1. 用本地小服务器打开（`python3 -m http.server`），或放到 GitHub Pages 上，网址打开就能玩；
2. 或者我写一个打包脚本，把图片转成内嵌数据，仍然导出一个 HTML 文件（会大一些）。

作品集展示建议用 GitHub Pages；平时试玩用打包后的单文件。接线由我来做。
